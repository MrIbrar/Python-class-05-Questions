# Python Class 02 – Practice Questions

This repository contains beginner-level Python programs using `while` and `for` loops to practice fundamental programming concepts such as iteration, input handling, condition checking, and working with basic data structures like lists and tuples.

---

## 📚 Topics Covered

- Printing numbers using loops (`while` and `for`)
- Multiplication tables
- Traversing lists and tuples
- Searching for an element in a tuple
- Using `break` and flags in loops

---

## 🚀 Programs Included

1. **Print numbers from 1 to 100 (using `while`)**
2. **Print numbers from 100 to 1 (using `while`)**
3. **Print multiplication table of a number (using `while`)**
4. **Traverse a list using `while` loop**
5. **Search a number in a tuple using `while`**
6. **Traverse a list using `for` loop**
7. **Search a number in a tuple using `for` loop**
8. **Print numbers from 1 to 100 (using `for`)**
9. **Print numbers from 100 to 1 (using `for`)**
10. **Multiplication table (using `for`)**

---

## 🛠️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/MrIbrar/Python-class-05-Questions
````

2. Navigate to the folder:

   ```bash
   cd Python-class-05-Questions
   ```

3. Run the Python file:

   ```bash
   python class5.py
   ```
